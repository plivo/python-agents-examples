# Design: gpt5.2-speechmatics-elevenflashv2.5-native

## Overview

Native voice agent using Speechmatics Voice Agent API for STT, OpenAI GPT 5.2-mini for LLM, and ElevenLabs eleven_flash_v2_5 for TTS. Client-side Silero VAD for fast barge-in. No orchestration framework.

## Architecture

```
Plivo (mu-law 8kHz) <-> Agent <-> Speechmatics STT (PCM16 s16le 8kHz, WS binary)
                                     | transcript (EndOfTurn)
                                   OpenAI GPT 5.2-mini (HTTP SSE streaming)
                                     | text chunks (sentence-buffered)
                                   ElevenLabs TTS (PCM16 24kHz, WS)
                                     | audio
                                   -> Plivo (mu-law 8kHz)
```

### Transport per service

| Service | Transport | Protocol |
|---------|-----------|----------|
| Plivo | WebSocket | JSON events + base64 mu-law |
| Speechmatics | WebSocket | JSON control + binary PCM frames |
| OpenAI GPT 5.2-mini | HTTP SSE | Streaming chat completions (only option) |
| ElevenLabs | WebSocket | JSON with base64 audio chunks |

## Audio Pipeline

| Hop | From | To | Function | Notes |
|-----|------|----|----------|-------|
| Plivo -> Speechmatics | mu-law 8kHz | PCM16 s16le 8kHz | `plivo_to_speechmatics()` | mu-law decode only, no resample (SM supports 8kHz) |
| Plivo -> VAD | mu-law 8kHz | float32 16kHz | `plivo_to_vad()` | decode + resample (Silero needs 16kHz) |
| ElevenLabs -> Plivo | PCM16 24kHz | mu-law 8kHz | `elevenlabs_to_plivo()` | resample 24k->8k + PCM-to-mu-law |

## Concurrent Tasks

### plivo_rx (persistent)
- Receives Plivo `media` events, decodes base64 mu-law
- Converts to PCM16 8kHz -> sends binary frames to Speechmatics WS
- Converts to float32 16kHz -> feeds Silero VAD
- VAD speech-start during AI response -> full barge-in flush

### speechmatics_rx (persistent)
- Listens to Speechmatics WS JSON events
- `AddSegment` with `is_eou: true` -> accumulates transcript
- `EndOfTurn` -> triggers `_generate_response()` with accumulated text
- All other events logged appropriately (partials at verbose, metrics logged)

### plivo_tx (persistent)
- Dequeues audio from `asyncio.Queue`
- Chunks to 160 bytes (20ms at 8kHz mu-law)
- Sends `playAudio` JSON to Plivo WS

### _generate_response (spawned per turn)
- Appends user transcript to conversation history
- Streams GPT 5.2-mini chat completion (HTTP SSE)
- Buffers text to sentence boundaries (`.!?,;:`)
- Each sentence -> ElevenLabs WS for synthesis
- Audio chunks -> `elevenlabs_to_plivo()` -> queued for plivo_tx
- Supports tool calling with follow-up generation

## Barge-in Flow (full flush)

1. Silero VAD detects speech-start locally
2. Cancel active `_generate_response` asyncio task
3. Send `{"event": "clearAudio"}` to Plivo (stops server-side playback buffer)
4. Send cancel context to ElevenLabs WS (stops TTS mid-synthesis)
5. Drain plivo_tx `asyncio.Queue` completely (discard queued audio)
6. Set `_is_responding = False`
7. Increment `_barge_in_count`
8. Emit `_emit_turn_complete(barge_in=True)`

## Speechmatics Configuration

- Profile: `SPEECHMATICS_PROFILE` env var (default: `adaptive`)
- Endpoint: `wss://preview.rt.speechmatics.com/v2/agent/{profile}`
- Auth: `Authorization: Bearer {SPEECHMATICS_API_KEY}`
- StartRecognition: `pcm_s16le` at 8000 Hz, `enable_partials: true`, language `en`
- Audio: raw binary WebSocket frames (not base64)

## Event Handling (all events consumed)

### Plivo events
- `start` -> extract callId/streamId, log session
- `media` -> decode + forward audio
- `stop` -> set `_running = False`, close connections
- Unknown -> log warning

### Speechmatics events
- `RecognitionStarted` -> log ready
- `AddPartialSegment` -> log at verbose level
- `AddSegment` (is_eou=true) -> accumulate transcript
- `EndOfTurn` -> trigger response generation
- `StartOfTurn` -> log turn boundary
- `SpeechStarted`/`SpeechEnded` -> log (diagnostic)
- `SessionMetrics`/`SpeakerMetrics` -> log metrics
- `AudioAdded` -> ignore (ack)
- `EndOfTranscript` -> log session closing
- `EndOfTurnPrediction` -> log at verbose
- `Error`/`Warning`/`Info` -> log at appropriate level
- Unknown -> log warning

### ElevenLabs events
- Audio chunk -> decode, convert, queue
- Alignment events -> log at verbose
- Errors -> log error

### OpenAI SSE
- Text deltas -> buffer to sentence boundaries -> send to ElevenLabs
- Tool call deltas -> accumulate by index
- `finish_reason: stop` -> flush remaining text
- `finish_reason: tool_calls` -> execute tools, generate follow-up

## Logging & Observability

### Three-tier verbosity (LOG_LEVEL env var)
- `verbose` -- per-packet stats, VAD frames, queue sizes, partials, TTFB
- `normal` (default) -- turn lifecycle, final transcripts, LLM responses, TTS timing
- `quiet` -- errors and session start/end only

### Structured logging methods
- `_log(stage, msg)` -- normal level, binds call_id, elapsed_s, stage
- `_logv(stage, msg)` -- verbose only
- `_loge(stage, msg)` -- always visible, increments _error_count
- Format: `[{call_id}] [{elapsed:7.2f}s] [{stage}] {msg}`

### Per-turn metrics (reset each turn)
- `_turn_llm_ms` -- OpenAI streaming latency
- `_turn_tts_ttfb_ms` -- ElevenLabs time-to-first-audio-byte
- `_turn_tts_total_ms` -- total TTS synthesis time
- `_turn_tts_chunks` -- audio chunks received
- `_turn_tts_audio_s` -- total audio duration
- `_turn_stt_ms` -- Speechmatics EndOfTurn to transcript delivery

### _emit_turn_complete(barge_in)
Structured event with all per-turn metrics bound via logger.bind(event="turn_complete", ...).

### Session counters
`_turn_count`, `_barge_in_count`, `_error_count`, `_plivo_rx_bytes`, `_plivo_tx_chunks`, `_ttfs_samples`

### OTel tracing (optional)
- `_traced(span_name)` decorator: wraps `"llm"`, `"tts"`, `"stt"` in OTel spans
- TracerProvider + OTLP exporter in server.py
- HTTPX auto-instrumentation for OpenAI

### Log sinks (server.py)
- Stderr text (default) or JSON (LOG_FORMAT=json)
- JSONL file (LOG_FILE, 100MB rotation, 7-day retention)
- Redis Streams (REDIS_EVENTS_URL, XADD structured fields)

### pyproject.toml optional extras
- `[observability]` -- opentelemetry-api, -sdk, -exporter-otlp, -instrumentation-httpx
- `[streaming]` -- redis[hiredis]

## Config Placement

### agent.py owns
- `OPENAI_API_KEY`, `OPENAI_MODEL` (default `gpt-5.2-mini`)
- `SPEECHMATICS_API_KEY`, `SPEECHMATICS_PROFILE` (default `adaptive`)
- `SPEECHMATICS_URL` (constructed from profile)
- `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL_ID`
- `SYSTEM_PROMPT` (loaded from system_prompt.md)
- `PLIVO_CHUNK_SIZE = 160`
- `LOG_LEVEL`

### server.py owns
- `SERVER_PORT`, `PLIVO_AUTH_ID`, `PLIVO_AUTH_TOKEN`, `PLIVO_PHONE_NUMBER`, `PUBLIC_URL`
- Log sink configuration (JSON, file, Redis)
- OTel TracerProvider setup

### utils.py owns
- `PLIVO_SAMPLE_RATE = 8000`, `ELEVENLABS_SAMPLE_RATE = 24000`, `VAD_SAMPLE_RATE = 16000`
- VAD params: thresholds, min silence, chunk samples
- Audio conversion functions, SileroVADProcessor
