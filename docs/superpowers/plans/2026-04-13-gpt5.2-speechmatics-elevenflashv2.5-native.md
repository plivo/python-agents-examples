# gpt5.2-speechmatics-elevenflashv2.5-native Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a native voice agent using Speechmatics Voice Agent API (STT), OpenAI GPT 5.2-mini (LLM), and ElevenLabs eleven_flash_v2_5 (TTS) with Plivo telephony and client-side Silero VAD.

**Architecture:** Pipeline: Plivo mu-law 8kHz <-> Agent <-> Speechmatics STT (PCM16 8kHz WS binary) + Silero VAD (float32 16kHz local) -> GPT 5.2-mini (HTTP SSE) -> ElevenLabs TTS (PCM16 24kHz WS) -> Plivo. Four concurrent asyncio tasks: plivo_rx, speechmatics_rx, plivo_tx, and per-turn response generation.

**Tech Stack:** Python 3.10+, FastAPI, uvicorn, aiohttp (Speechmatics/ElevenLabs WS), httpx (OpenAI SSE), Silero VAD (ONNX), loguru, OpenTelemetry (optional)

### Task 3: Implement SpeechmaticsSTT class and inbound agent.py

**Files:**
- Create: `gpt5.2-speechmatics-elevenflashv2.5-native/inbound/agent.py`
- Create: `gpt5.2-speechmatics-elevenflashv2.5-native/inbound/system_prompt.md`

- [ ] **Step 1: Write inbound/agent.py**

Key components:
1. **OTel tracing** -- optional, no-op pattern (identical to reference)
2. **`SpeechmaticsSTT` class** -- WebSocket client for Speechmatics Voice Agent API:
   - `__init__(call_id, profile)` -- profile from `SPEECHMATICS_PROFILE` env
   - `connect()` -- opens WS to `wss://preview.rt.speechmatics.com/v2/agent/{profile}` with Bearer auth, sends `StartRecognition` (`pcm_s16le`, 8000 Hz, `enable_partials: true`, language `en`), waits for `RecognitionStarted`
   - `_receive_loop()` -- handles ALL Speechmatics events:
     - `RecognitionStarted` -> log
     - `AddPartialSegment` -> log at verbose
     - `AddSegment` (is_eou=true) -> accumulate transcript, put on transcript queue
     - `StartOfTurn`/`EndOfTurn` -> log turn boundaries; EndOfTurn puts sentinel on transcript queue
     - `SpeechStarted`/`SpeechEnded` -> log diagnostic
     - `EndOfTurnPrediction` -> log verbose
     - `SessionMetrics`/`SpeakerMetrics` -> log
     - `AudioAdded` -> ignore
     - `EndOfTranscript` -> log, break
     - `Error`/`Warning`/`Info` -> log at appropriate level
     - Unknown -> log warning
   - `send_audio(pcm_8k: bytes)` -- sends raw binary WS frame
   - `close()` -- sends EndOfStream, closes WS
   - Properties: `latest_transcript`, `clear_transcript()`
3. **Config constants** -- `OPENAI_API_KEY`, `OPENAI_MODEL` (default `gpt-5.2-mini`), `SPEECHMATICS_API_KEY`, `SPEECHMATICS_PROFILE` (default `adaptive`), `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID`, `ELEVENLABS_MODEL_ID`, `LOG_LEVEL`
4. **Tool functions** -- `check_order_status`, `send_sms`, `schedule_callback`, `transfer_call` (identical to reference)
5. **`VoiceAgent` class** -- same structure as reference but with Speechmatics instead of Sarvam:
   - `__init__` -- session state, queues, VAD, metrics (identical counters)
   - Structured logging: `_log`, `_logv`, `_loge`, `_emit_turn_complete`
   - `_build_tools()`, `_handle_function_call()`
   - `_generate_llm_response()` -- OpenAI streaming chat completions via httpx (HTTP SSE, NOT WebSocket). Stream text deltas, buffer tool calls, handle follow-up after tool execution.
   - `_synthesize_with_elevenlabs()` -- ElevenLabs WS TTS (identical to reference)
   - `run()` -- connect STT, generate greeting, run streaming tasks, log summary
   - `_run_streaming_tasks()` -- 3 concurrent tasks: plivo_rx, plivo_tx, stt_watch
   - `_receive_from_plivo()` -- decode audio, forward to Speechmatics (binary PCM), run VAD, barge-in with full flush (cancel task, clearAudio to Plivo, cancel ElevenLabs, drain queue)
   - `_watch_transcripts()` -- convergence gate (VAD speech_ended + STT transcript)
   - `_commit_turn()`, `_process_text_turn()`, `_send_checkpoint()`, `_send_to_plivo()`
6. **`run_agent()`** public function

Key difference from reference: `SpeechmaticsSTT.send_audio()` sends raw binary frames (not JSON+base64 like Sarvam). The Speechmatics WS connection needs `Authorization: Bearer` header.
